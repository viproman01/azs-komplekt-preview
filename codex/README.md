# АЗС Комплект — прототип

Откройте `index.html` напрямую в современном браузере. Сборка, сервер, установка пакетов и интернет не нужны. Все ресурсы локальные, шрифты системные; сетевых запросов, CDN и внешних зависимостей нет.

Сделаны все разделы из TASK.md, мобильное меню, четыре категории и карточка КМН 125-100-160 с характеристиками со шильдика. Логотип `assets/logo.png` вырезан из фото; остальные изображения — явно обозначенные SVG-заглушки. Исходный шильдик открывается в диалоге. Макет рассчитан на десктоп 1440 и мобильный экран 390 px.

Форма проверяет имя и телефон, показывает ошибки и результат проверки. Данные не отправляются и не сохраняются. Кнопки категорий и насоса подставляют оборудование в форму. Контактный телефон доступен по ссылкам `tel:`.

Описания и ассортимент отмечены как временные/«уточнить». Цены, наличие, сроки, сертификаты и клиенты не выдуманы. Ex и EAC приведены только как знаки на шильдике. Структурные ориентиры: [EVALT](https://evalt.kz/) и [azsk74.ru](https://www.azsk74.ru/); их сведения не перенесены на компанию из Самары.

Проверены синтаксис JavaScript, наличие локальных ресурсов, уникальность ID, цели внутренних ссылок, данные шильдика, контакты и XML всех SVG. Проверки пройдены.

**Браузерная проверка заблокирована средой:** Chrome headless завершается SIGABRT, WebKit получает отказ macOS sandbox, фоновый браузер инструмента недоступен. Поэтому открытие страницы, отсутствие ошибок консоли и визуальный результат на 1440/390 в браузере не подтверждены. Отчёт: `qa/report.json`. Для повторной проверки при доступном Chrome и Node 24: `node qa/browser-check.mjs`. Скрипт открывает `file://`, проверяет оба размера и интерактивность, отслеживает консоль/сеть и сохраняет скриншоты; публичный сервер не запускает.

Все файлы задачи находятся в текущей папке; публикации и push не выполнялись. Рабочая копия: `main`, без исходных коммитов и remote. Разделение работ: основной агент — HTML/CSS/JS/README, агент ресурсов — `assets/`, агент проверки — `qa/` и `.gitignore`. Исходные TASK.md и order-photo.jpg сохранены.
