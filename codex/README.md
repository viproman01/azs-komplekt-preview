# АЗС Комплект — прототип

Откройте `index.html` в современном браузере. Это статический сайт на русском: сборки, установки пакетов, CDN, внешних шрифтов и библиотек нет. Все изображения и иконки локальные. Зелёная палитра, технические иллюстрации и плашка «Прототип» сохранены.

## Что изменено по TASK2.md

- Каталог содержит пять направлений: насосы, топливораздаточные колонки, резервуары и ёмкости, запчасти и комплектующие, сервис и обслуживание. У каждой категории есть SVG-заглушка, описание и кнопка «Запросить», которая выбирает нужную категорию и переводит к форме.
- Сохранены карточка КМН 125-100-160, параметры предоставленного шильдика и диалог с `order-photo.jpg`. Другие позиции и подкатегории — «уточнить».
- Добавлены пять пунктов «Почему мы», этапы «заявка → подбор → предложение → поставка → сервис» и услуги: поставка, монтаж и пусконаладка, сервисное обслуживание. Неизвестные условия отмечены словом «уточнить». Цены, сроки, история, лицензии, гарантии, отзывы и партнёры не придуманы. Ex и EAC обозначают только знаки на исходном шильдике.

Структурные ориентиры: [EVALT](https://evalt.kz/) и [azsk74.ru](https://azsk74.ru/). Их факты, бренды, показатели и отзывы не перенесены на компанию из Самары.

## Форма заявки

Имя и телефон проходят клиентскую валидацию. При ошибке показаны пояснения, `aria-invalid` и фокус на первом неверном поле. Кнопки каталога и услуг подставляют интерес в форму.

После успешной проверки появляется блок **«Заявка сформирована»** с именем, телефоном, интересом, комментарием и пометкой «Заявка с сайта-прототипа». Пустые необязательные поля получают значение «Уточнить». Текст вставляется как текст, без выполнения HTML. WhatsApp получает тот же текст через `encodeURIComponent`.

В обработчике `submit` синхронно вызывается `window.open` для `https://wa.me/79225353969?text=…` с `noopener,noreferrer`. Две кнопки-ссылки — «Написать в WhatsApp» и «Позвонить» — остаются на странице и при блокировке новой вкладки. Сообщение отправляет пользователь в чате WhatsApp. Повторное редактирование очищает ранее сформированный результат, чтобы не использовать устаревшие данные.

Сайт не использует серверную обработку, токены, `fetch`, XHR или браузерное хранилище. Заявка передаётся внешнему сервису только при открытии WhatsApp после отправки формы или по соответствующей ссылке.

## Карта

До нажатия «Показать карту» iframe не существует: начальная загрузка сайта не обращается к внешним сервисам. Кнопка создаёт iframe OpenStreetMap с адресом `https://www.openstreetmap.org/export/embed.html?bbox=49.9,53.1,50.4,53.35&layer=mapnik`. Карта центрирована на Самару, точный адрес не отмечен: координаты объекта неизвестны. Рядом явно указано: **«Точное положение на карте — уточнить»**.

Есть ссылки «Открыть в Яндекс Картах» и «Открыть в OpenStreetMap». Обработчик ошибки и таймер ожидания возвращают кнопку повторной загрузки. Поскольку содержимое чужого iframe недоступно для проверки, даже после события `load` сохраняется подсказка на случай пустой или недоступной карты. Ссылки и телефон доступны всегда. CSP запрещает сетевые соединения скриптов (`connect-src 'none'`) и разрешает для iframe только `https://www.openstreetmap.org`.

## Проверки

Запуск из этой папки:

```sh
node --check js/main.js
python3 -B qa/static-check.py
node qa/browser-check.mjs
```

Скрипт статической проверки использует доступные Python-библиотеки lxml/Pillow и Node; они не являются зависимостями сайта. **24 из 24 статических проверок пройдены**: структура и вложенность HTML, уникальность ID, цели ссылок/`aria`/`label`, локальные ресурсы и SVG, размеры и форматы favicon, синтаксис JavaScript, категории, контакты, значения шильдика, CSP, структура формы и отложенная карта. Отчёт: `qa/static-report.json`. Контрольный поиск удалённой формулировки по рабочим файлам не нашёл совпадений; исходные задания `TASK*.md` и журналы `*.log` сохранены без изменений и исключены из поиска.

**Браузерная проверка недоступна в этой песочнице:** Chrome headless дважды завершился `SIGABRT` до открытия страницы; резервный фоновый браузерный инструмент также недоступен. Поэтому отсутствие ошибок браузерной консоли, горизонтальной прокрутки и визуальная адаптивность на **390/768/1440 px не подтверждены браузером**. `qa/report.json` честно содержит `status: blocked`; новые скриншоты не созданы. Статическая проверка не заменяет визуальную HTML5-валидацию и проверку внешних сервисов.

`qa/browser-check.mjs` подготовлен для повторного запуска при доступном Chrome и Node 24. Он проверяет три ширины, скролл, локальные изображения, отсутствие внешних запросов до действий пользователя, категории, валидацию и текст WhatsApp, блокировку popup, меню/Escape/фокус, диалог шильдика, загрузку/ошибку/повтор карты. В тесте WhatsApp перехватывается, внешние запросы блокируются, сервер и публичный туннель не запускаются. Другой установленный Chrome можно указать через `QA_CHROME_PATH`.
