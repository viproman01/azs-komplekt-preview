# АО «АЗС Комплект» — прототип сайта

Статический прототип визитки/каталога для АО «АЗС Комплект» (г. Самара): оборудование для АЗС, взрывозащищённые насосы.

## Как открыть

Откройте `index.html` в браузере (двойной клик или «Open with Live Server»). Сборка не нужна, CDN и сетевые запросы не используются.

```
index.html
css/styles.css
js/main.js
assets/          — logo.png (вырезан из order-photo.jpg) и фото-заглушки категорий
```

Адаптив: ориентиры 1440px (десктоп) и 390px (мобильный).

## Что внутри

- Шапка с логотипом и меню
- Hero с кнопкой «Получить предложение»
- Каталог категорий: насосы, колонки, резервуары, запчасти
- Карточка насоса КМН 125-100-160 с таблицей параметров с шильдика
- Преимущества, о компании, форма заявки (только клиентская валидация), контакты, подвал

Тексты без данных заказчика помечены «уточнить» / «нет данных». Цены, клиенты и сторонние сертификаты не выдуманы.
